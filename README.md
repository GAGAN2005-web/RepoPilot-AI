# RepoPilot AI

RepoPilot AI is an AI-powered GitHub repository understanding and engineering assistant.

It allows developers to provide a public GitHub repository and interact with its codebase using natural language.

## Planned Features

- GitHub repository ingestion
- Repository structure analysis
- Code and documentation parsing
- Intelligent code chunking
- Embeddings
- Vector search
- Retrieval-Augmented Generation (RAG)
- Source references
- LLM-powered repository questions
- Tool calling
- GitHub issue creation with confirmation
- Conversation history
- React frontend
- FastAPI backend

## Tech Stack

- Python
- FastAPI
- Pydantic
- GitHub API
- LLM API
- Embeddings
- Vector database
- SQLite / PostgreSQL
- React
- Docker
